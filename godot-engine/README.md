# Roadseer · 片段一：干旱公路

最新反馈：后续改为“14日准备＋7日三日凌空”的灾难周期，并加入制作台与图纸。见[新目标草案](../docs/gdd/周期灾难与制作目标草案.md)。本文和当前运行程序仍描述旧的8节点试玩，新周期尚未实现。

可玩的单局原型，Godot 4.6。验证的问题：**设备、补给和战利品争夺格子时，奖励与扩容是否引发有意义的重排；自动战斗能否解释配置的作用。**

当前是8个节点、7段行驶、3场自动战斗的一趟旅程，有胜利、失败和重开。体验目标约15—20分钟，实际耗时和趣味性尚待真人试玩，不能用脚本通关代替。

## 启动

在仓库根目录执行：

```sh
./godot-engine/play.command
```

也可以在 Finder 中双击本目录的 `play.command`。当前脚本使用已安装的 `/Applications/Godot.app/Contents/MacOS/Godot`；其他位置可通过 `ROADSEER_GODOT_BIN` 指定。跨平台使用 Godot 4.6 打开 `project.godot` 后运行，尚未制作 Windows 发行包。

所有开发和验收使用 CLI / 可用的 Godot MCP，禁止 Computer Use。本轮会话没有 Godot MCP 工具，已用 CLI 启动、引擎内输入事件和引擎导出的画面进行验证，未宣称完成 MCP 验收。

## 开始玩

1. 阅读顶部库存和左侧车厢。驾驶位与3个客座各占1×2，可搬移但在此片段不能丢弃。点击下方“出发”。
2. 路边车库三选一。奖励先放在右侧地面，点击它再点击车厢放置；未装车不会生效。
3. **点击物品 → R旋转 → 点击目标格。** 右键或Esc取消。红色预览表示冲突，失败不会丢失物品。选择点是物品左上角。
4. 选中一箱物资，点击同类箱子可以合并到上限，超出部分留在原处。物资耗尽后箱子消失，腾出格子。
5. “放到地面”可以暂时腾位置。本节点还可以装回；离开时会列出地面物品，必须明确确认放弃。
6. 普通遭遇自动开火。金色弹道表示己方射击，红色为敌方攻击，蓝色弧线表示防护。右侧逐拍记录耗弹、装甲减伤、耗电拦截和车损。Space暂停，按钮可切换×1/×2播放。
7. 预警信号处选择干河床或旧水站，再选一组奖励。两条路线的燃油、饮水、敌人和营地供水不同。
8. 维修营可以花6材料扩到4×8，或花2材料修复6耐久。材料必须在车内；扩容不是强制通关条件。
9. 最后整备后挑战出口守卫。通关或失败可重开相同样本，或换一组奖励和敌人数值。没有局外属性成长。

## 空间和补给

- 水、口粮、油、弹药、材料、原料、修理包均是实体占格物品，没有隐藏的无限资源库存。
- 常规行驶：1油、1水、1口粮。维修营之后每段耗2水；水站绕路单段耗2油。缺水或口粮每份扣4耐久，燃油不够则本局结束。
- 集水器每段生产2水；厨房用1原料生产2口粮。生产先补已有堆叠，再尝试空格；无法保存的产物会明确记录溢出，厨房完全没有存放空间时不消耗原料。
- 生产只随行驶推进，整理和暂停不会无限产出。电力是车辆每场战斗充满的基础电容3电，加每块蓄电池4电；当前不模拟发电链。
- 机枪每2拍耗1弹，6伤害并受装甲减免；穿甲炮每4拍耗2弹，16伤害且无视装甲。拦截器每次耗1电，最多挡3伤害；装甲板每次减1伤害，防护各只计一套。
- 无可用火力时触发代价高的应急撞击，避免无限等待。战斗期间不能搬移、拾取或使用修理包。

## 代码

- `scripts/vehicle_state.gd`：实体库存、节点与奖励、供给结算、确定性逐拍自动战斗。逻辑不依赖窗口，可用CLI驱动。
- `scripts/vehicle_grid.gd`：网格、旋转预览、选择与放置请求。
- `scripts/battle_view.gd`：车辆、敌人血条、弹道、拦截与受损提示。
- `scripts/main.gd`：原生界面、输入、确认弹窗、播放速度与暂停。

## 验证记录（2026-10-22）

Godot 4.6.2 / macOS。本轮通过CLI调用引擎完成验证；临时验证驱动与日志位于 `/tmp/roadseer-*`，没有使用Computer Use。

- 完整旅程：集水器＋机枪／水站路线，以及穿甲炮／干河床路线，在A、B两组样本都存在合法通关路径。测试会按规则装箱、消耗、拾取、扩容和战斗，没有直接发放无限资源或跳过终点战斗。
- 规则边界：重叠、越界放置失败保持原物；合并堆叠保留多余数量；地面物品未经确认不能出发；战斗锁定库存；缺弹路径能够结束并给出失败原因。
- 引擎输入：通过窗口内输入事件完成出发、选择奖励、拾取、非法放置、Esc取消、R旋转、合法放置、放到地面、触发放弃弹窗、取消后重新装车、进入战斗、暂停／继续。暂停期间计时停止。
- 引擎画面：检查初始、满载、战斗、路线选择与通关界面；检查1440×900及1280×820画面。
- 仍需用户验证：首次体验是否易懂、整理是否有趣、战斗因果是否足够清楚、实际一局时长，以及是否愿意再开另一套构筑。
