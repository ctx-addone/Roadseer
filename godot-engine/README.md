# Roadseer Godot PC 原型

P0 验证版，Godot 4.6；以4×6车辆网格测试空间取舍、扩容和生产链。设计依据见 [PC车辆背包与MVP提案](../docs/gdd/PC车辆背包与MVP提案.md)。

## 启动

用 Godot 导入本目录的 `project.godot`，按 F6/F5 运行主场景。当前 Mac 可在项目根目录执行：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path godot-engine
```

其他 PC 安装 Godot 4.6 后打开同一项目。本轮只在本机 macOS 验证，未导出或验收 Windows 发行包。

## 如何体验

1. 点击左下待装区的集水器，再点击中间空格放置。
2. 点击已放设施进入搬移；R旋转；点击确认；右键或Esc取消；“拆到待装区”保留设备。
3. 制造厨房、培养皿等，再从待装区安装。悬停制造按钮可读效果。
4. 探索获得材料和原料，每三次探索一次简化遭遇。休整也会结算生产、耗水和食物。
5. 用材料升级：2级扩大至4×8；3级扩大至6×8并解锁二层、选择探索／家园方向；4级解锁车顶。
6. 车顶安装太阳能，配合集水器、培养皿、厨房形成供给。注意只有安装的设备生效。
7. 探索6次，达到3级且安装厨房，保有水与食物各4时可挑战终点。

初始四个座位各1×2，驾驶位不可拆卸且只能在第一层；其余可搬至待装区。后备箱是后两排的视觉分区，当前不限制用途。房间占格和设备尺寸都是测试参数。

## 当前边界

- 已实现：设备占格、旋转搬移、碰撞／越界／楼层检查、扩容、三层切换、制造、探索资源、简化战损、生产与消耗、测试分支、终点检查、失败和重开。
- 未实现：物资实体占格、完整副本／世界、剧情、实时战斗、乘员、通道／楼梯、存档、设备能耗天气模拟、完整十级路线。
- V1/V2/V3 目前是策划方案，不是启动菜单中的三个已完成模式。
- P0只存内存，退出重置。待装区为调试便利提供临时设备托盘，不是正式游戏的无限仓库。
- 资源初始容量每种30，存储室每件增加15。生产超容量部分丢弃；精确经济平衡未定。
- 本轮不以程序通关证明玩法有趣，也不宣称已达到目标时长。

## 源码

- `scripts/vehicle_state.gd`：设施参数、空间验证、车辆和资源状态。
- `scripts/vehicle_grid.gd`：网格呈现与点选摆放。
- `scripts/main.gd`：原型界面、输入与状态展示。

原型应在验证后按结论收敛或重构，不直接当作正式产品架构。使用的 Godot 启动方式参见[官方命令行文档](https://docs.godotengine.org/en/stable/tutorials/editor/command_line_tutorial.html)。
