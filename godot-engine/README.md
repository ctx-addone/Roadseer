# Roadseer · 里程与宝箱试玩

2026-11-02新增独立[木工、收纳与供弹demo](../docs/testing/2026-11-02-storage-demo/README.md)：小箱9槽、长箱18槽、空座载货、原木加工与邻接供弹。启动时指定 `res://scenes/storage_demo.tscn`；默认场景仍是下文的原公路版。

2026-10-30：在原车辆背包基础上，替换每日一次选路线机制。现在沿公路持续行进，速度越高，同样游戏时间跑得越远、发现的宝箱越多。普通物资自动收取，大型地点选择停车探索或略过。仍保留14天准备＋7天三日凌空目标。

## 启动

在仓库根目录运行 `./godot-engine/play.command`，或在 Finder 双击该文件。Godot 默认位置为 `/Applications/Godot.app/Contents/MacOS/Godot`，可用 `ROADSEER_GODOT_BIN` 指定其他位置。当前没有游戏存档，关闭后本局进度丢失。

## 先玩一轮行进

1. 点击左侧“开始行驶”。基础车速40 km/h；每秒推进5游戏分钟，约6秒后到达20km的第一个宝箱，饮水自动入舱。
2. 普通宝箱优先合并已有物资，再放入空格；装不下会停车，溢出物资出现在车厢下方，整理后继续。驶离前仍会确认放弃未装物资。
3. 第60km发现破损车辆，可以花1小时搜索并自动战斗，或略过继续行驶。到达地点时暂停计时，无需抢点按钮。
4. 停车后搭建制作台（2金属、1小时），成品在待装区。把车内金属旋转为竖向放回原位置，腾出右下2×2空间安装制作台；点击制作台打开二级界面。
5. 选择发动机升级：40→60 km/h花4金属、1小时，60→80花6金属、1小时。车速提高后，同样路程用时更少。也可以先扩容：6金属/1小时升为4×8，再花8金属/1小时升为4×10。
6. 当日时间用完，或准备提前休息，停车并“结束当天”。夜间结算水粮、高温与睡眠；里程保持，第二天接着向前走。

## 时间、燃油和搜集

| 项目 | 当前规则 |
|---|---|
| 每天时间 | 360分钟，不结转；整理、查看详情和地点决策免费 |
| 真实车速 | 初始40，发动机两级升级为60、80 km/h |
| 播放倍速 | ×1／×2同时加快时间和里程，只缩短等待，不增加每游戏小时收益 |
| 普通宝箱 | 每20km一个，循环获得水2、粮2、油1、金属2、弹药3、布料2 |
| 大型地点 | 每60km一处，循环为破损车辆、电站遗址、生活补给点、武装物资车 |
| 探索地点 | 固定1小时，含搜索与战斗；略过免费。战利品放入待装区，手动整理 |
| 制作／扩容／发动机升级 | 每次1小时；材料必须装车，成品在待装区 |
| 使用现有修理包 | 30分钟，恢复最多10车体 |
| 行驶燃油 | 每累计行驶1小时准备期耗1油，高温期2油；每小时开始前预付 |
| 停车与跨天 | 保留已预付的剩余行驶时间，反复启动不额外扣油；进入第15天时旧准备期额度清零 |
| 高温外出 | 每预付1小时另耗1水、2健康；无水或无油会停车，仍可驻车过夜 |

宝箱和地点按总里程生成，不随日结刷新。无手动驾驶、碰撞拾取或操作时限；地点布局与物资顺序当前固定，便于验证速度收益。机械臂、随机公路和新的路线分叉尚未实现。

## 背包与成员

- 车辆4列×6行，竖直展示；驾驶位和3个客座各1格，主角1人坐驾驶位，客座为空。小爱是自动作战系统，不计为成员。
- 单人床占2格，可旋转，每床睡1人；无热伤、缺水和缺粮且有床时，夜间恢复最多2健康。无床不恢复。
- 点击设施使用；拖动物品整理，或点击移动后选择格子。R旋转、Esc取消；同类物资可合并，超出堆叠上限保留。
- 行驶、地点决策和战斗时锁定布局。行驶可随时点左侧“靠边停车”整理；Space暂停，暂停本身不解锁整理。
- 待装区属于当前停靠点。继续行驶／结束当天会离开，未装物资经确认后丢弃，不是无限随车仓库。
- 扩容车厢可独立滚动。菜单可开启“减少道路动态”，保留里程、事件与奖励反馈。

## 大型地点与制作

| 地点 | 战利品 | 遭遇 |
|---|---|---|
| 破损车辆 | 金属4、布料3、弹药4 | 掠食兽，自动战斗 |
| 电站遗址 | 元件3、金属2、油4 | 自动战斗；首次取得发电机和制冷机图纸 |
| 生活补给点 | 水6、粮4、油3 | 准备期安全；高温期热兽 |
| 武装物资车 | 弹药10、修理包1、布料2 | 装甲守卫 |

| 配方 | 材料 | 空间与效果 |
|---|---|---|
| 制作台 | 金属2 | 2×2，提供高级制作、扩容和发动机升级 |
| 单人床 | 金属2、布料2 | 1×2，无需制作台 |
| 隔热层 | 金属2、布料4 | 2×2，被动减热2 |
| 发电机 | 金属3、元件2 | 1×2，给制冷机供电 |
| 制冷机 | 金属2、元件2、布料1 | 2×2，配套发电机耗1油/晚、减热3 |
| 装甲板 | 金属3 | 1×2，每次受击减伤1 |
| 修理包 | 金属2、布料1 | 1×2，使用时修复最多10车体 |

除了床与制作台，其余配方需要车内制作台。能源图纸需探索电站，其余开局已知。水、粮、油、弹药每箱最多12；金属、布料、元件每箱最多8；修理包每箱最多2。所有补给与材料实体占格。

## 三日凌空

第15～21天热强度为3、3、4、5、5、4、3。余热＝热强度－隔热2－有效制冷3，最低0。每晚耗水1＋向上取整(余热÷2)、口粮1，余热每级伤害4；缺1水额外伤害6，缺1粮额外伤害4。有效制冷要求已装车的发电机、制冷机、开启开关和至少1油。健康或车体归零失败；完成第21晚生存即胜利。

抗灾预报只计算当前设备和库存下的剩余灾难夜晚，不含未来行驶、制作或搜索收益。2026-11-01已补齐新版正常开局两种策略21天模型通关，见[Windows验收记录](../docs/testing/2026-11-01-windows/README.md)；真人整局体验与平衡仍待试玩，旧版通关结果不能当作新版通关证明。
