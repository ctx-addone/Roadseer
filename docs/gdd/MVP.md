# Roadseer 三种玩法提案与 MVP 验证

> 历史候选稿：平台已改为PC/Godot，当前空间规则与V1/V2/V3范围见[PC车辆背包与MVP提案](PC车辆背包与MVP提案.md)。本文原A/B/C不作为当前实现指令。

日期：2026-10-22｜版本：0.2｜状态：A／B／C 并列验证草案，未选定产品方向。

系统见 [GDD](GDD.md)，综合比较见[类型方案](游戏类型方案.md)。本文的数量、节奏、槽位和结算规则均为原型提案，不是对小说的逐项还原。


## 阅读顺序与共用边界

第1—9节展开 A 的七日经营验证；第10节和第11节分别定义 B、C 的独立验证范围；第12节给出比较顺序。A 写得更详细是此前草稿的延续，不代表产品已经选择 A，不能将其行动点和失败规则套到 B、C。

三案共用车辆成长、模块／雕像选择和环境适应的主题。每案先交付独立最小体验，再决定是否进入该案完整 MVP；当前不同时开发三案。所有方案先用单机、测试存档、有限内容，不加入真实市场、多人或商业化。

## 1. A：要验证什么

**提示、生产与车辆构筑，能否形成“探索有取舍、建设有变化、灾难前有准备”的体验？**

只验证一个完整沙漠阶段和一小段冰雪预知／迁移场景，不制作完整前三世界。原型加速车辆成长，使玩家能在有限内容中比较分支，正式版节奏另定。

| 假设 | 可观察行为 | 不支持假设的信号 |
|---|---|---|
| 提示有价值 | 根据箱内风险、路线信息调整装备与计划 | 忽略提示，或只点被标为最优的选项 |
| 生产有成长感 | 用集水器盈余支持探索、交易和晋级 | 收益不可感知，或仅等待即可通关 |
| 分支有差异 | 两分支用不同成本解决同一威胁 | 一条路线在所有关键场景全面更优 |
| 预知影响筹备 | 返回后制造、交易或安装抗寒物品 | 只有剧情展示，没有可执行准备 |

## 2. 原型形式

单机、本地存档、节点探索、回车管理、简化战术遭遇结算。暂用二维图标、面板与基础行驶表现；横竖屏、镜头、美术风格未定。

主要界面：路线与时间／成本预览；车辆库存／生产／模块／雕像；事件和副本选择／结果。选择前展示已知成本与风险，结算后解释消耗和收益。

战斗用“交战／准备道具／撤离”选项承载。敌人威胁、武器、防护、消耗品决定结果，规则公开且可重复验证。本轮只验证准备和构筑，不代表动作手感验收，也不意味着正式版已取消实时战斗。

## 3. 最小内容规模

| 内容 | 范围 | 验证目的 |
|---|---|---|
| 世界 | 沙漠完整阶段＋冰雪预知片段、迁移落点 | 本世界闭环与跨世界筹备 |
| 时间 | 7游戏日，每日4行动点；第6日副本、第7日灾难 | 有限期限与准备节奏 |
| 车辆 | 1—3级基础成长，3→4级选越野／战车 | 晋级与一次专业选择 |
| 模块 | 集水器、储物箱、动力部件、强化轮胎、装甲、简易武器、保温设备 | 生产、空间、通行、防护与未来需求 |
| 雕像 | 树桩、人鱼、战争女神三件改编版 | 产出、图纸收益、遭遇修正取舍 |
| 节点 | 箱子、荒野、遭遇、商人、奖励入口、营地六模板 | 不同资源和风险组合 |
| 敌人 | 猛兽、拦路者两类 | 准备、防护、撤离成本 |
| 副本 | 一个入口二选一：当前资源挑战／冰雪预知 | 即时收益与未来情报 |
| 交易 | 一个 NPC，明确报价、库存和次数限制 | 盈余交换与补缺 |
| 资源 | 水、食物、燃油、维修材料、制造材料、核心、晋级图纸、模块图纸 | 行动成本与建设门槛 |
| 引导／存档 | 成本说明、升级预览、事件后保存和恢复 | 可理解、可验证的流程 |

制造材料首轮归并，不细分全部木料／橡胶／元件。使用成品雕像，精魄只作奖励来源说明，不实现完整雕像制造升级链。NPC 交易不是联网玩家市场。

## 4. 时间、资源和失败处理

### 4.1 行动与日终

行驶到一个节点、执行一次探索或制造各花1行动点。安装／卸下模块和雕像免费。访问商人花1点，访问内可按库存限额交换多项。进入并完成一次副本花1点，不额外跳过整天。所有费用在确认前显示。

第6日奖励入口作为当日可选节点出现，不要求停在随机特定位置；使用一次后关闭另一选项。

主动结束一天或行动点耗尽时，执行：生产产出→每日雕像事件→水与食物消耗→环境和状态结算→更新日期和行动点。可用库存不足时展示明确缺口；容量溢出允许选择保留／丢弃普通物资，不静默吞掉关键凭证。

日终只结算一次；读档不能重复生产、发放兔子。时间有限，不能无限休息绕过灾难期限。树桩以停车兔子事件表现，原型在日终停车时统一结算。

### 4.2 保底资源与经济配置

开局提供首日最低补给；基础必经节点给集水器配方与材料；关键核心和晋级图纸通过里程碑保证获得，随机箱子仅提供额外收益。精确产出、消耗、配方、敌人属性需在实现前写成测试配置，本稿不宣称已平衡。

核心路径必须在28行动点内可达。进入实现前列出一条保底资源账本，覆盖收集、制造、升级、一次副本与灾难准备，不靠随机掉核心解决通关可达性。

### 4.3 失败与退路

- 缺水／食物先造成可见状态损失，状态耗尽则测试失败，不能无预警清档。
- 缺燃油可用一次应急求援，以材料和时间换最低返程燃油；应急油不可出售，不能循环获利。
- 背包满可丢弃一般物资；核心和晋级凭证独立记录，容量溢出不丢失。
- 遭遇失败扣耐久与有限普通物资；撤离代价提前显示，保留图纸和车等级。
- 灾难失败显示能力缺口，可从第7日开始的检查点重试；恢复完整检查点状态，不能累加产出和奖励。

以上为原型体验保护，不代表正式版失败规则已定。

## 5. 车辆晋级、模块与分支

### 5.1 加速测试配方

| 晋级 | 建设资格 | 消耗 | 新反馈 |
|---|---|---|---|
| 1→2 | 已安装集水器 | 1核心 | 仓储与模块容量扩大 |
| 2→3 | 至少2种已安装且有效的模块 | 1核心＋1张3级晋级图纸 | 解锁分支准备、额外雕像槽 |
| 3→4 | 至少3种已安装且有效的模块，完成路线里程碑 | 1核心＋1张4级晋级图纸 | 选择越野或战车 |

这些是原型配方，与原著条件不同。核心、晋级图纸均有保证出现的里程碑来源；晋级不消耗已装模块。选择前展示两分支收益、代价与保留资产，取消不扣资源。

### 5.2 槽位与构筑

| 等级 | 模块槽 | 雕像槽 |
|---|---|---|
| 1 | 2 | 0 |
| 2 | 3 | 1 |
| 3—4 | 4 | 2 |

每件模块占1槽，同名只能装一件；背包中的成品不生效。储物箱占用模块槽，换取一般库存容量。完整供电、重量和空间拼装后置。

越野在险路耗油、通过与撤离上有优势；战车在正面遭遇、护送和降低战损上有优势。用“高收益险路”和“守点敌人”两个固定场景比较，避免只按伤害数值评估。

两个分支都能通过最终灾难，资源消耗组合不同。保底路线应在第5日完成4级分支，留出第6日奖励与第7日挑战。具体倍率写进测试配置，保证相同初始资源下都有通路。

## 6. 雕像与提示的最小规则

| 雕像 | 原型测试效果 | 取舍 |
|---|---|---|
| 树桩 | 每日1份兔肉原料，可在 NPC 换食物 | 稳定生存与交易供给 |
| 人鱼 | 指定图纸节点追加1碎片，3碎片换一件非晋级模块图纸 | 长期技术收益 |
| 战争女神 | 猛兽标签节点威胁降低一档 | 减少遭遇成本 |

这是改编效果，不是原著精确数值。2级1槽、3级2槽，集齐三件仍需取舍。

每日产出资格在日初锁定，当天装树桩从下一日起产出；当天拆下则当日不产出。人鱼与战争女神在事件开始时检查装备。重复拆装、读档不能刷收益；日终、事件、冷却分别记录，不混用。

提示首轮免费：普通风险直接显示，每个可侦察节点可额外揭示一次特定隐藏信息。信息在行动前可读，反复打开内容不变。

示例：“箱内有一张生产图纸，开启会引来猛兽。”玩家可带武器、准备诱饵或放弃，至少两种方案可执行且成本不同。提示不直接把按钮标成唯一正确答案。

## 7. 七日流程与世界迁移

| 阶段 | 预期体验 | 变化 |
|---|---|---|
| 第1—2日 | 学习成本、提示、探索，装集水器并升2级 | 水开始自产、容量扩大 |
| 第3—4日 | 生产盈余、交易、雕像取舍并升3级 | 用资源交换补齐建设 |
| 第5日 | 完成里程碑，选4级分支 | 同一场景有不同解法 |
| 第6日 | 选资源副本或冰雪预知 | 当前收益与未来情报取舍 |
| 第7日 | 准备并通过沙暴灾难，迁移冰雪 | 长期资产保留，新需求出现 |

这是保底引导路径，不强制所有玩家同序。预知片段展示冰面与低温，给一份保温设备材料；返回后可提前制造保温设备。资源副本给当前灾难所需物资；未预知者进入冰雪仍有基础求生路径，只是准备成本更高。

沙暴灾难检验通行、防护与补给。越野可走较长但安全的绕路；战车可走短险路并承担燃油维修成本。挑战前显示缺口并允许回准备界面，满足条件后只结算一次。

迁移保留等级、分支、模块、雕像、图纸与剩余资源；清除沙漠节点访问、日程和商人库存，重置为冰雪第1日。冰雪落点提供一次抗寒／补给选择验证预知价值，结算后原型结束，不制作完整冰雪世界。

## 8. 验收场景与观察方法

以下是未来实现的验收目标，不是已完成测试。测试内容可用简化资源和美术，但界面不能把未实现功能显示为可用。

| 编号 | 场景 | 通过标准 |
|---|---|---|
| V01 | 新存档走保底路线 | 28行动点内完成生产、晋级、一次副本、灾难与迁移，无随机关键资源锁死 |
| V02 | 同一危险箱的不同应对 | 提示有依据；至少两种解法可执行且代价不同 |
| V03 | 集水器安装前后 | 账目有产出变化，盈余可支持行动或交换 |
| V04 | 同资源比较两分支 | 都可通关；险路与守点各体现一种优势 |
| V05 | 三雕像、两个槽 | 第三件需替换；效果按标签触发，收益有记录 |
| V06 | 预知与资源副本对照 | 奖励不同；预知可提前准备，未预知仍能生存 |
| V07 | 世界迁移 | 长期资产保留、局部状态重置、冰雪需求生效 |
| V08 | 保存、读档、重试 | 日产、副本奖励、晋级消耗、灾难迁移各只执行一次 |
| V09 | 缺油、满背包、失败 | 有明确成本与退路，不静默损失关键凭证 |

可用性试测建议邀请3—5名体验者，不口头提示答案，观察能否说明下一目标、因提示改变一次决定、说出升级后的新能力、主动为冰雪准备。记录不理解的术语和停滞点，小样本只用于发现问题，不能证明留存和市场规模。

## 9. 范围外与进入实现的条件

本轮不含真实玩家市场、联网车队、实时多人比赛、伙伴完整 AI、养殖链、全部五种4级车、5—10级车、完整第二／第三世界、舰队海战、神国权限、商业化和离线收益。

进入实现前若选定 A，先补齐保底资源账本、节点配置和两分支参数。按“探索资源→生产晋级→构筑副本→灾难迁移”逐段实现，用对应场景验收。本文是可评审草案，不是完成平衡后的生产排期。

## 10. B：动作 RPG／载具刷装验证案

### 10.1 体验与循环

首轮聚焦俯视角车战，玩家直接驾驶、躲避、开火。暂不制作完整离车操作。循环为出击准备→短路线战斗→精英掉落→回车维修换装→再次挑战。角色经验等级暂不加入，用车体阶段、模块和武器支撑成长。

长期保留车辆、图纸、模块和雕像；遭遇失败损失本次未带回的普通战利品，已带回装备保留。它是持续积累式原型，与 C 的局内清空不同。

### 10.2 内容与交互

| 项目 | 最小范围 | 用途 |
|---|---|---|
| 战斗 | 一个场景，两类普通敌人、一个精英 | 验证走位、瞄准、攻击预警 |
| 武器 | 快速连射、慢速范围攻击两种 | 相同敌人下比较操作变化 |
| 模块 | 六种，覆盖机动、防护、武器、补给 | 配装取舍，不先堆大量随机词条 |
| 雕像 | 两件，分别强化机动收益和正面抗压 | 验证战斗联动 |
| 晋级／分支 | 一次试验晋级，机动型／装甲型二选一 | 分支改变战斗方式 |
| 基地 | 装配、制造弹药、维修三项 | 补给直接服务出击 |
| 世界／预知 | 战斗后短冰雪试炼和提前预警 | 换装能应对环境差异 |
| 存档 | 回基地保存，重试恢复出击前状态 | 不重复领取奖励 |

第一个体验片段只做基础驾驶、两武器换装和一个精英；操作成立后再补完整清单。触控原型需实际试握，键鼠可玩不能代替手机操作验证。正式平台性能和设备覆盖另验收。

### 10.3 验收与淘汰条件

- B01：不依赖口头指令，能完成移动、开火、躲避、撤回基地。
- B02：对同一精英切换两武器后，攻击距离、出手节奏或走位需求不同。
- B03：机动／装甲分支都能通过挑战，分别减少不同失误成本。
- B04：雕像改变可观察战术，如保持移动换收益；不只在面板加伤害。
- B05：掉落带回后可比较、装配并用于下一次出击，失败与保存不刷奖励。
- B06：预警后更换防滑／保温准备，在冰雪试炼中有可见收益。

若基础驾驶和攻击在没有掉落奖励时就缺乏吸引力，先修手感或调整战斗定位，不靠增加装备数量掩盖。若需要同时做好车战、离车、经营才有完整体验，应重新收窄范围。

## 11. C：短局 Roguelite／车辆构筑验证案

### 11.1 体验与循环

首轮用节点路线与简化遭遇承载随机组合，暂不加入完整实时战斗；由此与 A 比较的重点是持久经营和局内构筑的差异。循环为选起始车→随机模块／雕像→调整选路→一次分支晋级→局终灾难→结算重开。

局内保留库存、车体等级、模块、雕像和临时效果；局终重置。局外只保留图鉴与候选池解锁，首轮不增加永久攻击／血量。暂停存档记录随机种子和进度，中断可继续，失败重开不伪装成继续存档。

### 11.2 内容与交互

| 项目 | 最小范围 | 用途 |
|---|---|---|
| 起始构筑 | 机动、装甲两种 | 不同起点，避免只靠开局随机 |
| 路线 | 一张短图，两个阶段，资源／战斗／奖励节点 | 有限风险与奖励规划 |
| 随机池 | 六种模块、四种雕像 | 至少形成机动、火力两组可解释联动 |
| 晋级 | 局内一次方向选择 | 根据已获得能力调整构筑 |
| 副本 | 资源／预知二选一 | 当前强度与后段适应取舍 |
| 世界 | 沙漠前段、冰雪后段两个规则片段 | 局内环境变换，而非持久家园迁移 |
| 结局 | 一个灾难挑战，结束后查看构筑 | 解释胜负并引导重玩 |
| 随机与存档 | 固定种子可复现，记录奖励领取 | 区分设计问题和随机问题 |

第一个体验片段只验证两组组合、两条路线和一次重开；确认组合会改变选择后再扩大奖励池。不需要为了证明随机性就让关键通关物完全依赖运气。

### 11.3 验收与淘汰条件

- C01：相同种子、相同行动能复现奖励与遭遇；读档不重新抽奖。
- C02：在不同起始构筑或奖励选择下，玩家主动改变路线或装配。
- C03：同一环境威胁至少有两种处理方法，不因缺一件随机物必败。
- C04：预知后仍有至少一次获取／更换应对能力的机会。
- C05：失败明确列出重置和保留内容，能暂停继续，不会误清局外解锁。
- C06：两次重玩出现不同的有意义选择；只换物品名称而策略相同不算通过。

若每次必选同一套组合，先处理构筑平衡；若玩家主要痛苦是建设被清空，应重新审视重开结构，而非直接添加大量永久属性。

## 12. 如何比较并推进

先分别走读三案十分钟体验脚本，再选择两案做最小体验片段；独立原型通过核心验收后，才决定某一案完整 MVP 的投入。此处不要求先完成 A 才允许验证 B／C。

各案都观察目标理解、主动选择、升级变化、继续游玩的意愿与原因。A 额外看经营筹备，B 看操作换装，C 看组合重玩。轮换体验顺序，尽量保持素材完成度和指导方式相近，不用一个方案的独特指标淘汰其他方案。
