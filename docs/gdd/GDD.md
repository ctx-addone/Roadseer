## 2. 核心体验与循环

核心交互已确定为车辆网格背包：初始4×6，驾驶位与3个客座暂各1×2，升级扩展尺寸，最多两层车内＋一层车顶。长期经营、持续奖励与流派构筑共同保留。具体规则和V1/V2/V3流程见上方最新提案。

**靠提示做出更好的探索决策，把一辆勉强维生的旧车，建设成能生产、交易、战斗并跨越灾难的移动家园。**

玩家的主要资产是车辆及其模块、雕像、图纸、伙伴与情报。角色装备支撑离车行动。成长必须带来能力变化：原本需要搜刮的水开始自产，无法通过的路段可以进入，面对新环境可以主动准备。

| 时间尺度 | 玩家目标 | 关键变化 |
|---|---|---|
| 一次行动 | 判断是否探索、怎样付出成本 | 根据提示选择路线、装备或撤离 |
| 一个游戏日 | 保证生存并积累盈余 | 安排行驶、探索、生产、维修与休息 |
| 一个世界 | 完成针对性建设并通过灾难 | 用产出、交易、副本补齐能力缺口 |
| 跨世界 | 形成自己的车辆流派 | 保留建设，适应新的资源和威胁 |
| 长期 | 从移动基地发展到组织与世界权限 | 伙伴、车队、舰船和跨世界建设 |

“游戏日”由游戏行动推进，不与现实日期绑定；离线收益尚未确定。

```mermaid
flowchart LR
    A[观察世界与提示] --> B[规划路线和装备]
    B --> C[行驶与探索]
    C --> D[搜集 战斗 交易]
    D --> E[制造 生产 维修]
    E --> F[模块与雕像构筑]
    F --> G[晋级或应对灾难]
    G --> A
```

探索把资源带回车上；经营把资源变成稳定供给与升级；情报帮助玩家把供给投入下一次挑战。战斗用于获取资源和检验构筑，其占比由游戏类型决定。

## 3. 核心成长路线

### 3.1 主成长阶段

| 阶段 | 主要矛盾 | 关键解锁 | 成长反馈 |
|---|---|---|---|
| 求生起步 | 库存消耗、缺少工具 | 集水、基础制造、维修、提示 | 从被动消耗到能主动补给 |
| 稳定生存 | 探索成本高、生产不足 | 食品加工、仓储、雕像、2—3级车 | 可以绕路探索并保留盈余 |
| 专业分工 | 容量与安装条件有限 | 4级车型分支、专用模块、伙伴分工 | 探索、战斗、经营路线分化 |
| 移动基地 | 多系统需要协同 | 5—6级平台、生态生产、自动化 | 管理生产链与多设备协作 |
| 综合平台 | 地形和组织规模扩大 | 7级车体构建、跨地形能力、研究 | 车辆突破轮式形态 |
| 世界权限 | 发现等级体系与世界规则 | 8—10级门槛、世界核心与权限剧情 | 从适应规则到参与改变规则 |

上述是长期内容组织方式，不要求首版覆盖全部。MVP 的共用验证目标是成长与选择，各类型的具体范围分别定义。

### 3.2 五条成长线

| 成长线 | 获取方式 | 解锁内容 | 作用 |
|---|---|---|---|
| 车辆等级 | 配件达标、核心、晋级图纸、阶段条件 | 空间、安装能力、车型与分支 | 主要阶段门槛 |
| 模块与雕像 | 探索、制造、交易、特殊奖励 | 产出、抗性、武器、事件效果 | 同级内形成不同构筑 |
| 生产与技术 | 配方、设备、原料、研究 | 自给、加工链、自动化 | 降低成本，为升级供给 |
| 角色与伙伴 | 装备、任务、关系、专长 | 离车能力、养殖、研发、后勤 | 补足车辆能力，形成分工 |
| 情报与权限 | 提示、侦察、预知副本、剧情 | 风险、未来需求、后期权限 | 改善决策与选择范围 |

车辆等级、配件等级、品质、角色等级、眷属等级和技能等级是不同维度。“20级召唤幽灵船技能”不能记为“20级车辆”。角色是否使用经验等级尚未确定，不用通用经验条替代车辆晋级条件。

### 4.2 游戏晋级规则建议

统一过程：**检查建设条件 → 检查凭证 → 预览变化／分支 → 确认 → 扣除消耗 → 更新车辆与安装能力。**

- 资格与消耗分开：已安装且有效的配件用于资格判定，默认不会因晋级消失；核心和晋级图纸按配方消耗。这是手游提案，不是原著各阶段的统一结论。
- 按不同有效模块计数，重复安装同一模块不重复满足数量要求；雕像是否计入配件由物品配置声明。
- 晋级预览展示新增能力、保留资产、转移规则、不能继续安装的设备与资源缺口。
- 取消不扣资源，晋级一次完成，失败不产生半升级状态。
- MVP 用独立测试配方验证流程，不直接照搬原著材料数量。

### 4.3 分支结构

原著并非每级多选一：1→2、2→3直接升级；3→4明确选方向；4→5只确认主角路线有重火力／全能两种；5→6未见分支；6→7开放车体构建。外形伪装、单模块强化和车型分支分别记录。

| 4级方向 | 主要能力 | 建议的选择代价 | 首轮范围 |
|---|---|---|---|
| 超级越野车 | 速度、地形通过、路线选择 | 正面防护和生产容量较弱 | MVP 候选 |
| 步兵战车 | 装甲、火力、战斗收益 | 燃油、弹药与维护负担较高 | MVP 候选 |
| 豪华房车 | 生产、空间、生活与伙伴后勤 | 高危路线突破能力较弱 | 后续；经营优先时可替换战车原型 |
| 蒸汽机车 | 怪诞技术与特殊图纸 | 专用资源和维护限制 | 后续 |
| 生化车间 | 生物改造、环境适应 | 特定材料与状态副作用 | 后续 |
| 隐藏方向 | 特殊物品解锁 | 获取路径和效果单独设计 | 后续 |

表中的代价是设计建议。各分支面对同一生存目标，用不同成本解决；不能把某条路线做成主线必选。MVP 在单次测试存档内固定分支，通过重开比较另一条；正式版转职、洗点及跨路线兼容规则待验证。

### 5.1 资源、生存和制造

资源分为行动消耗（水、食品、燃油、弹药）、制造材料（金属、木料、橡胶、玻璃、电子元件）、能力解锁（图纸）、晋级凭证（核心、晋级图纸）与特殊资源（精魄）。品质和等级分离。

环境产生具体需求：沙漠要水与降温，冰雪要保温、防滑、供暖，极夜要照明和心情支持，污染要净化与防护。第163章心情值让床铺、料理、装饰、娱乐有价值；完整伤病、疲劳、心情机制可分期加入。

制造区分“解锁配方”“拥有成品”“安装生效”；拿到图纸不等于获得能力。工具影响分解收益，分解不能超过制造投入形成无成本循环。背包满、缺燃油等状态需要可执行退路，见 MVP。

### 5.2 车辆模块与自动化

模块分动力行走、防护、武器、生存生活、生产仓储、控制辅助六组。安装检查车型／等级与实际承载能力；后期可加入供电、载重、结构强度，MVP 先用明确槽位。

生产、生活、战斗设备竞争空间，形成机会成本。自动化随设备能力开放，用于收集、清障、驾驶和武器控制，逐步降低重复操作负担。

公共游戏系统负责规则、制造、频道和结算；提示系统揭示隐藏信息；小爱／灵境负责车辆与设备执行。三者不能混成同一等级。提示的建议成长线为危险感知→物资识别→路线分析→战术推演→有限预测，属于新增设计，不是原著明确升级表。

## 6. 特殊摆件／雕像系统

雕像提供稳定产出、掉落修正、环境保护、条件触发或主动技能。生命周期：**获取图纸／成品 → 制造 → 满足门槛 → 装配生效 → 升级或替换。**

| 原著样例 | 效果与作用 | 章节线索 |
|---|---|---|
| 幸运的人鱼雕像 | 提高图纸获取量，未给出明确概率 | 10、21 |
| 有吸引力的树桩 | 每天吸引一只兔子撞车，形成稳定猎物来源 | 73、90 |
| 战争女神的守护 | 降低猛兽袭击概率 | 56 |
| 丰收女神 | 车内作物生长速度、产量翻倍 | 146 |
| 清洁与沐浴女神 | 清洁空气、水和车体，有毒物超标时净化 | 158 |
| 龙女仆托尔 | 清洁、龙尾肉、心情恢复，部分效果可升级 | 196—197 |
| 雪人雕像 | 防风雪、冰面打滑、寒冷伤害等 | 203 |
| 花间精灵 | 生长速度＋30%、产量＋50%、患病率降低20% | 437 |
| 奥克因精魄雕像 | 较弱蜘蛛绕行、不攻击 | 450 |
| 瓦尔基里的守护 | 主动免伤1分钟，冷却1小时 | 690 |

上述数值仅为原著参考。人鱼与战争女神有车辆安装门槛；部分摆件能计入车辆晋级配件。部分可用材料或精魄升级，不能假设所有雕像同一升级方式。

游戏规则建议：有限摆件槽支持产出／掉落／防护取舍，同名只生效一件。每个效果声明作用对象、触发时机、叠加规则、上限和持续范围。每日事件按游戏日结算一次，存档、读档、拆装与跨世界不能重复领取；主动效果独立记录冷却。树桩兔子通过停车事件表现；领取与日终规则在 MVP 中简化。

换世界保留摆件，环境专用效果按新世界规则生效。避免一件早期摆件永久消除所有后续生存压力。固定槽位、同类互斥与叠加上限都是改编提案。

## 7. 副本、竞赛与下一世界预知

| 类型 | 目标 | 奖励 | 作用 |
|---|---|---|---|
| 资源副本 | 搜集、清理、撤离 | 材料、图纸、核心 | 补齐当前建设缺口 |
| 奖励副本 | 从若干挑战中择一 | 稀有物、应对物资、情报 | 制造机会成本 |
| 预知副本 | 短暂接触下一世界 | 环境情报与应对物资 | 返回当前世界筹备 |
| 竞赛 | 竞速、争夺、阶段对抗 | 凭证、名次奖励 | 检验车辆与构筑 |
| 剧情／遗迹副本 | 调查特殊地点 | 技术、人物与世界线索 | 推进长期内容 |

副本是局部规则容器，世界是阶段环境与资源规则容器；竞赛是一种目标和结算形式。三者可以组合，普通探索节点不必都做成副本。

原著预知线索：第82—83章寒冰之桥，第230—232章提前进入废土，第500及509—510章山顶入口。通常与奖励关卡有关，不是每次竞赛获胜自动开启，也不是每世界必有，第630章存在未能预知的情况。

建议过程：出现入口→展示可知风险和奖励类别→选择一项→完成／撤离／失败→只结算一次→返回世界。进入前说明携带限制、时间流逝、死亡代价和返程方式。

核心选择是“补眼前资源”还是“投资未来情报”。情报应能改变可执行计划，如提前制造防滑轮胎、囤积净水，而不只是增加背景文本。伙伴分开刷材料和探情报可作为后续协作玩法。

## 8. 世界、灾难与阶段推进

每个世界定义：环境主题、持续规则、资源分布、道路／节点池、敌人与事件、阶段目标、灾难条件、进入／离开规则和情报内容。

建议过程：进入世界→获取局部信息→探索建设→奖励机会→最终准备→灾难检验→结算迁移。开篇七天灾难可作首轮模板，不视为所有后期世界的固定规则。

| 世界方向 | 主要压力 | 促进的建设 | 内容阶段 |
|---|---|---|---|
| 沙漠 | 水、高温、燃油与距离 | 集水、降温、仓储、选路 | MVP 主世界 |
| 冰雪 | 保温、防滑、风雪 | 供暖、轮胎、储能、抗寒 | MVP 预知片段及迁移落点 |
| 废土／污染 | 空气、水与怪物风险 | 净化、防护、药品 | 后续 |
| 极夜等变体 | 可见性、生活与心情 | 照明、食物、舒适设施 | 后续 |
| 海洋／舰船战场 | 水上通行、舰队、特殊武器 | 涉水、舰船、组织能力 | 独立扩展 |

建议跨世界保留车辆、模块、雕像、图纸和剩余物资；重新初始化地图访问、世界日程、局部事件和商人库存；退出副本清除副本临时能力。世界迁移、每日结算和奖励均只执行一次。

灾难检验前期建设。应提供多种满足条件的手段，如设备、防护消耗品、绕路，而非用单件随机掉落锁死通关。正式版失败代价随类型选择决定，不能在尚未选择 Roguelite 时默认清空长期建设。

## 9. 伙伴、交易、战斗与后期扩展

伙伴可以拥有独立车辆和专长。赵婉婉以动物亲和、养殖后勤为参考，不能直接简化为同车属性加成。第230章分开探索奖励副本是分工样例，第671章自然之心是能力线索。建议首轮用 NPC 交易验证生产盈余价值，完整伙伴 AI、车队通信、公共仓库和玩家市场后置。

原著前期以物易物，物资价值随世界需求变化。生产路线为搜刮食品→加工→种植养殖→稳定供应链→移动生态基地；第178章生产交换链、第229章生态园可供后续细化。

战斗从个人工具、弩枪成长到车载火力和自动化。动作、策略或简化结算与游戏类型一起选择，首轮不并行开发多套完整战斗。

海战有水陆共同战场和独立航海经营两种扩展。第592—607章联合制药海战、第676—725章汽车与舰船对抗、第1107—1216章前后航海篇提供来源。舰船是平行成长路线，不是所有汽车必然升级成战舰。世界核心、权柄、神国和规则修改作为长期方向，不进入 MVP。

## 10. 设计约束与下一步

1. 每次成长至少改变一种能力或选择，不能只靠数值膨胀。
2. 提示提供可信依据，保留风险处理与资源取舍，避免直接给唯一答案。
3. 车型分支、模块、雕像职责分明，不能全部变成伤害倍率。
4. 生产缓解旧需求，同时由新资源、新环境、新能力保持探索动机。
5. 世界切换改变需求组合，不能只换贴图和增加血量。
6. 先验证一个世界的闭环和下一世界筹备，再扩展内容深度。
