# 木工、收纳与邻接供弹 demo

日期：2026-11-02。独立场景 `godot-engine/scenes/storage_demo.tscn`；默认公路场景保留原有规则，便于比较。此demo依据本次讨论实施，不表示新A/B/C方向已经选定。

用户试玩反馈（2026-11-02）：核心玩法基本能成立，但需要做很大的调整才能变得好玩和顺畅。后续优先收敛操作流程、反馈、节奏与资源取舍；本轮技术通过不代表体验问题已经解决。

## 已实现

- 原木：20km首个托盘回收3份，此后每120km再回收3份；是原有普通物资之外的独立回收，不减少水粮油掉落。装不下会停车并保留剩余。
- 合成：1原木→4木板，10分钟，无需工作台；4木板→制作台，30分钟；8木板→小木箱，30分钟，需要制作台；16木板→长木箱，60分钟，需要制作台。仍使用配方列表，不含手摆九宫格合成。
- 小箱外部1格、内部9槽；长箱外部2格、内部18槽，可旋转。槽位是容量单位，不是另一套物品形状拼图：每组密封饮水/燃油占2槽，其他可堆叠小件占1槽。不能装设备、家具或其他箱子。
- 弹药1格/60发，口粮1格/6份，饮水1格/6升；燃油保持两格/12份。初始及掉落弹药按原射击次数换算成发：机枪一次3发、穿甲炮一次6发。不是照现实体积完成的最终物资平衡。
- 空客座承载一件一格物资或小箱；驾驶位不可载货。载货与座椅共用一个车厢格，移动座位会带着货物移动。尚未实现招募/换座，因此未新增实际乘员占用切换流程。
- 将物资拖到箱子上可收纳；点击箱内物资取出到待装区后继续放置。整箱可移动或卸下。箱内库存参与HUD、制作材料和日常消耗；地面箱不提供随车资源，离开时按地面确认规则连同内容舍弃。
- 箱子可以只接收弹药。自动拾取优先合并已有堆叠，再入箱、借用空座、使用空地；不能容纳的部分保留。当前不含逐物品指定目标箱或复杂排序面板。
- 机枪弹匣18发、穿甲炮36发；共边弹药包/载弹箱支持自动装填，斜角不算。远处库存可在停车时手动装填，不能战中全车取弹。选中武器或供应箱时绘制供弹连接线；武器显示弹匣数量，详情显示邻接可用量与全车储备。

## 试玩流程

1. 行驶约6秒到20km，点击靠边停车。打开右侧“木工与收纳合成”，加工3次木板。
2. 选中底部金属，按R，再点回原位置，把金属旋转为竖直。制作工作台并放在右下空出的2×2空间。
3. 点击工作台进入木工合成，做小木箱；放到空客座上，再把弹药拖到箱子上。点击箱子可查看9槽内容。
4. 移动载弹箱到机枪右侧原弹药位置，观察供弹线。继续行驶至60km，停车探索，观察自动装填及耗弹。
5. 也可把箱子搬远，查看机枪“邻接可补给”变为0；停车手动装填后，机枪仍能使用弹匣中已有的弹药。
