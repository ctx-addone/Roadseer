## 本次真人试玩建议

先玩第1—3天，完成一次“准备—出发—搜集—装车—制作—日结”循环，再决定是否继续整局。

1. 点击主角座位、空座和床，确认能理解人数、占格与睡眠容量。
2. 搭建制作台；把金属旋转成竖向放回，腾出右下2×2安装制作台。
3. 在左侧点“破损车辆”，查看右侧情报，在左侧出发；观察暂停、射击和车损反馈。
4. 把金属和弹药合并进车内；决定带走哪些物资，保留床铺。
5. 结束当天，核对水粮消耗、实际恢复量；第2天在制作台扩容，继续搜集材料。
6. 第3天开始在隔热或能源方向中选择，观察图纸追踪能否帮助决定去哪里。

以上为试玩前的建议；实际反馈及暂停决定见上方“真人试玩反馈与暂停记录”。
