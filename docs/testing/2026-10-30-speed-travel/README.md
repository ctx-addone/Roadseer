# 速度与里程试玩验证

日期：2026-10-30。Godot 4.6.2 / macOS / OpenGL Compatibility。对应[本轮设计](../../superpowers/specs/2026-10-30-distance-travel-design.md)。

## 结果

5组检查最终均 `failures=0`，退出码0。行进改为时间与里程驱动，替换旧的每日单次选路模型；新输入与周期脚本覆盖当前规则，旧脚本和结论可在此前提交684cc98追溯。

| 检查 | 证据与结果 |
|---|---|
| 成员睡眠 | [crew.log](crew.log)：1人、单格座椅、双格床、驾驶位约束、健康恢复上限及替代床制作通过 |
| 距离与边界 | [journey.log](journey.log)：三档车速、帧步长一致性、反复停车、跨日持续里程、燃油预付、溢出守恒、出发确认、地点只结算一次、自动战斗、缺时探索、高温、升级上限、制作和维修耗时通过 |
| 周期集成 | [cycle.log](cycle.log)：从正常开局用实际搜集材料，完成前3天制作台、扩容、战斗和电站图纸，进入第4天，里程366.67km，车体34，车厢4×10；另用明确配置的灾难局面验证7晚日结与纯预报一致 |
| 拖放 | [drag.log](drag.log)：实际引擎输入验证移动、非法格、待装物资、抓取偏移、Esc取消、长车厢滚动与裁切 |
| 原生界面 | [input.log](input.log)：实际鼠标/键盘视口输入验证开始、暂停、播放倍速、停车、查看床、探索、战斗、升级、略过与日结；主循环采用受控时间步长，保证结果可重复 |

容量及燃油充足、全部略过大型地点的6小时比较：

| 车速 | 里程 | 普通宝箱 |
|---|---|---|
| 40 km/h | 240 km | 12 |
| 60 km/h | 360 km | 18 |
| 80 km/h | 480 km | 24 |

比较使用大容量测试局面与发动机等级预设，目的为验证数学关系。实际游戏的停车、探索、制作与容量会降低里程，不能将此表当作正常开局收益承诺。

## 验证边界

- 未使用 Computer Use 操作 Godot；当前未接入 Godot MCP。Godot CLI 启动、引擎输入事件和截图验证完成，不等同真人试玩。
- 地面确认弹窗的取消回调通过信号验证；弹窗显示由真实按钮输入触发，出发确认的模型路径另有断言。
- 原生测试初次的最小窗口断言误将1440逻辑坐标与1280物理窗口比较；已改成同一视口坐标系，并结合截图复核，通过。
- 原生进程偶有 macOS 输入法 IMKCFRunLoopWakeUpReliable 提示；最终运行无脚本错误，退出0。
- 只验证了新行进系统前三天合法搜集与建设，以及配置局面的7晚灾难结算；尚未完成新版从第1天到第21天的整局平衡验收。旧版两条通关路线不能作为新版证明。
- 地点和普通宝箱顺序固定；没有机械臂、程序化路线、存档或正式美术。速度是否让行进更有趣，仍需用户实际试玩。
